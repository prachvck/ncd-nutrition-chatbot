# rag/sources — เอกสารต้นทางของฐานความรู้ RAG

ฐานความรู้หลักอยู่ใน `rag/ncd_knowledge.py` (25 ชิ้น เรียบเรียงจาก WHO, NIDDK, NHLBI/DASH,
KDOQI 2020, AHA, กรมอนามัย — มี `source` + `url` ทุกชิ้น)

โฟลเดอร์นี้ใช้เพิ่มเอกสารทีหลังโดยไม่ต้องแก้โค้ด: สรุปเอกสารเป็นไฟล์ `.md` ที่มี front-matter
(ดูรูปแบบใน `rag/source_loader.py`) แล้วรีสตาร์ทแอป ระบบจะ embed ใหม่ให้เอง

ไฟล์ที่ไม่มี front-matter (เช่น `english/WHO_healthy_diet_factsheet.md`) เป็นต้นฉบับเก็บไว้อ้างอิง
ไม่ถูกโหลดเข้า RAG (เนื้อหาถูกสรุปไว้ใน ncd_knowledge.py แล้ว)
