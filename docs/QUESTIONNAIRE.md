ให้ผู้ทดสอบกรอก **หลัง** ทำตาม `docs/USER_TEST_SCRIPT.md` เสร็จ · ใช้เวลาประมาณ 5 นาที

**วิธีสร้างใน Google Forms**
- ส่วน B, C, E ใช้ชนิดคำถาม **"สเกลเชิงเส้น" (Linear scale) 1–5** โดยตั้งป้าย 1 = ไม่เห็นด้วยอย่างยิ่ง, 5 = เห็นด้วยอย่างยิ่ง
- **คงเลขนำหน้าคำถามไว้ตามนี้** (เช่น `CUQ1.`, `F1.`) เพราะสคริปต์ `eval/cuq_score.py` ใช้เลขนี้หาคอลัมน์
- ตั้งทุกข้อในส่วน B เป็น "จำเป็น" ไม่งั้นคิดคะแนน CUQ ไม่ได้

## ส่วน A — ข้อมูลทั่วไป

**คำชี้แจง (ใส่ในคำอธิบายแบบฟอร์ม)**
> แบบสอบถามนี้เป็นส่วนหนึ่งของปริญญานิพนธ์ คณะเทคโนโลยีสารสนเทศ สจล. เพื่อประเมินแชทบอทแนะนำอาหาร
> สำหรับผู้ป่วยโรคไม่ติดต่อเรื้อรัง (NCDs) ข้อมูลใช้เพื่อการศึกษาเท่านั้น ไม่เปิดเผยรายบุคคล
> ไม่มีคำตอบถูกหรือผิด ตอบตามความรู้สึกจริงได้เลย
> ข้อมูลในแชทบอทเป็นเพียงข้อมูลประกอบ ไม่ใช่คำแนะนำทางการแพทย์

- A1. ยินยอมให้ใช้คำตอบและบันทึกการใช้งานแชทบอทเพื่อการศึกษา — ☐ ยินยอม (จำเป็น)
- A2. ชื่อที่ใช้ตอนกรอกโปรไฟล์ในแชทบอท (ใช้จับคู่กับบันทึกการใช้งาน ไม่เปิดเผย) — ข้อความสั้น
- A3. ช่วงอายุ — ☐ ต่ำกว่า 20 ☐ 20–29 ☐ 30–39 ☐ 40–49 ☐ 50–59 ☐ 60 ขึ้นไป
- A4. ใช้แอป LINE บ่อยแค่ไหน — ☐ ทุกวัน ☐ สัปดาห์ละหลายครั้ง ☐ นานๆ ครั้ง
- A5. เคยใช้แชทบอทหรือแอปบันทึกอาหาร/สุขภาพมาก่อนไหม — ☐ เคย ☐ ไม่เคย
- A6. ตอนกรอกโปรไฟล์ในแชทบอท เลือกโรคแบบไหน (ไม่ต้องเป็นข้อมูลจริง) — ☐ เบาหวาน ☐ ความดันโลหิตสูง ☐ โรคไต ☐ โรคหัวใจ ☐ โรคอ้วน ☐ ไม่ได้เลือก (เลือกได้หลายข้อ)

## ส่วน B — ความใช้ง่ายของแชทบอท (Chatbot Usability Questionnaire, CUQ)

> แปลจาก Chatbot Usability Questionnaire (Holmes et al., 2019; Ulster University) 16 ข้อ เรียงตามต้นฉบับ
> ข้อคี่ = ด้านบวก ข้อคู่ = ด้านลบ · 1 = ไม่เห็นด้วยอย่างยิ่ง … 5 = เห็นด้วยอย่างยิ่ง

| ข้อ | คำถาม (ภาษาไทย) | ต้นฉบับ |
|---|---|---|
| CUQ1. | บุคลิกของแชทบอทดูเป็นธรรมชาติและน่าสนใจ | The chatbot's personality was realistic and engaging |
| CUQ2. | แชทบอทดูเป็นหุ่นยนต์เกินไป | The chatbot seemed too robotic |
| CUQ3. | แชทบอทต้อนรับดีตอนเริ่มใช้งานครั้งแรก | The chatbot was welcoming during initial setup |
| CUQ4. | แชทบอทดูไม่เป็นมิตรเลย | The chatbot seemed very unfriendly |
| CUQ5. | แชทบอทอธิบายได้ดีว่าทำอะไรได้และมีไว้เพื่ออะไร | The chatbot explained its scope and purpose well |
| CUQ6. | แชทบอทไม่ได้บอกเลยว่ามีไว้เพื่ออะไร | The chatbot gave no indication as to its purpose |
| CUQ7. | ใช้งาน/ไปยังเมนูต่างๆ ของแชทบอทได้ง่าย | The chatbot was easy to navigate |
| CUQ8. | ใช้แชทบอทแล้วสับสนได้ง่าย | It would be easy to get confused when using the chatbot |
| CUQ9. | แชทบอทเข้าใจสิ่งที่ฉันพิมพ์ได้ดี | The chatbot understood me well |
| CUQ10. | แชทบอทไม่เข้าใจสิ่งที่ฉันพิมพ์หลายครั้ง | The chatbot failed to recognise a lot of my inputs |
| CUQ11. | คำตอบของแชทบอทมีประโยชน์ เหมาะสม และให้ข้อมูลดี | Chatbot responses were useful, appropriate and informative |
| CUQ12. | คำตอบของแชทบอทไม่ตรงกับสิ่งที่ถาม | Chatbot responses were irrelevant |
| CUQ13. | แชทบอทรับมือได้ดีเมื่อเกิดข้อผิดพลาดหรือพิมพ์ผิด | The chatbot coped well with any errors or mistakes |
| CUQ14. | แชทบอทดูรับมือกับข้อผิดพลาดไม่ได้เลย | The chatbot seemed unable to handle any errors |
| CUQ15. | แชทบอทใช้งานง่ายมาก | The chatbot was very easy to use |
| CUQ16. | แชทบอทซับซ้อนมาก | The chatbot was very complex |

**การคิดคะแนน CUQ (0–100)** ตามคู่มือต้นฉบับ:
`CUQ = ((ผลรวมข้อคี่ − 8) + (40 − ผลรวมข้อคู่)) / 64 × 100`
ค่าอ้างอิงจากงาน validation ≈ 68 (ใกล้เคียง SUS)

## ส่วน C — ความพึงพอใจรายฟีเจอร์ (1 = ไม่พอใจมาก … 5 = พอใจมาก)

- F1. การแนะนำเมนูอาหารที่เหมาะกับโรค/เป้าหมายของฉัน
- F2. การบันทึกอาหารด้วยการพิมพ์
- F3. การบันทึกอาหารด้วยการส่งรูป
- F4. การถามแคลอรี่/ถามว่ากินเมนูนี้ได้ไหม
- F5. หน้าสรุปย้อนหลังและวิเคราะห์รายสัปดาห์ (Dashboard)
- F6. คำเตือนเมื่ออาหารที่บันทึกไม่เหมาะกับโรค
- F7. ความรวดเร็วในการตอบของแชทบอท
- F8. ฉันเชื่อถือข้อมูลโภชนาการและคำแนะนำของแชทบอท

(เพิ่มตัวเลือก "ไม่ได้ใช้ฟีเจอร์นี้" ไม่ได้ใน Linear scale → ใส่หมายเหตุว่า "ถ้าไม่ได้ใช้ ข้ามได้" และตั้งเป็นไม่บังคับ)

## ส่วน D — ความรู้สึกและข้อเสนอแนะ (ปลายเปิด)

- D1. ส่วนไหนของแชทบอทที่ชอบที่สุด เพราะอะไร
- D2. ส่วนไหนที่ใช้ยาก สับสน หรือไม่ชอบ เพราะอะไร
- D3. มีตอนไหนที่แชทบอทตอบไม่ได้หรือตอบผิด (เล่าสั้นๆ ว่าพิมพ์อะไรไป)
- D4. ความรู้สึกโดยรวมหลังใช้ (เช่น สะดวก น่ารำคาญ อยากใช้ต่อ ฯลฯ)
- D5. อยากให้เพิ่มหรือปรับอะไร

## ส่วน E — ภาพรวม (1 = ไม่เห็นด้วยอย่างยิ่ง … 5 = เห็นด้วยอย่างยิ่ง)

- E1. ถ้าฉันเป็นผู้ป่วยโรคไม่ติดต่อเรื้อรัง ฉันจะใช้แชทบอทนี้ต่อ
- E2. ฉันจะแนะนำแชทบอทนี้ให้คนในครอบครัวหรือคนรู้จักที่มีโรคประจำตัว
- E3. โดยรวมแล้วฉันพอใจกับแชทบอทนี้
